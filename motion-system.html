Cinematic Motion System — BinDev

One motion language for the whole site. Smooth, purposeful, performance-safe. Driven by transform and opacity only. Every animation justifiable in one sentence (hierarchy, storytelling, feedback, state).

2. Loading sequence

  • 0ms: html opacity 0, body background shows immediately (no FOUC flash). Preload font weights WOFF2.
  • 0-320ms: mark (SVG signal dot) scales 0.6 to 1 with ease-out-soft; eyebrow fades in.
  • 320-900ms: hero headline enters word-by-word with stagger 48ms, y 24 to 0, opacity 0 to 1, blur 8px to 0.
  • 900-1100ms: subtext and CTA fade-up; CTA trailing icon rotates in.
  • 1100ms+: grid + glow fade from 0 opacity; page becomes scrollable; IntersectionObservers armed.
  • Never block interaction past 1.2s. Loading animation must be optional delay, not gate.

3. Text reveals

  • Hero H1: word-level opacity/transform, max 2 lines, tracking tightens 0.02em during reveal.
  • Body paragraphs: line-level fade with 60ms stagger per line, only once per session via sessionStorage flag.
  • Counters (metrics): number interpolation over 900ms on first view, tabular nums locked.
  • No scramble/decode effects on service copy (too noisy for B2B).

4. Image transitions

  • Lazy images start scale 0.96 + opacity 0; resolve scale 1 + opacity 1 over 700ms when 15% visible.
  • Duotone case study thumbs cross-fade to full color on hover over 400ms, ease-primary.
  • Aspect ratio reserved (aspect-[16/10]) to prevent CLS.
  • No parallax on images larger than 1MB on mobile.

5. Parallax and depth

  • Hero background grid: translate Y at 0.12x scroll; glow at 0.2x. GPU transform only.
  • Section hairlines: opacity from 0.4 to 1 as they approach viewport center.
  • Spotlight card borders: radial mask follows cursor with 120px radius, lerp 0.14 per frame.
  • No 3D transforms on scroll paths that include text (readability).

6. Scroll-triggered and pinned scenes

  • Feature bento: staggered fade-up, 80ms between cells, IntersectionObserver threshold 0.15, rootMargin -10%.
  • Featured work: sticky-stack. Each card pins at top: 0; as next card enters, previous scales to 0.92 and fades to 0.55. Pin duration ends when last card top hits viewport top.
  • Process rail: horizontal progress line draws as vertical scroll enters, tied to IntersectionObserver not scroll listeners.
  • Pinned hero (optional): only on desktop widths >= 1024px and only when prefers-reduced-motion: no-preference.

7. Hover and micro-interactions

  • Primary button: scale 0.98 on active; trailing icon translates 4px right and 1px up, scales to 1.05. 280ms.
  • Nav links: underline slides from left, 200ms, hairline to signal color.
  • Cards: spotlight border illuminates; inner content shifts 2px up. No scale bounce.
  • Magnetic pull (desktop only): cursor proximity pulls primary button 3px max, spring stiffness 120 damping 18. Disabled below 768px.
  • Focus: 2px signal outline, 2px offset, always visible.

8. Scene transitions

  • Route changes: crossfade 220ms with 8px vertical slide, respects motion preference.
  • Modal/overlay: backdrop blur 12px, content scale 0.98 to 1, opacity 0 to 1 in 280ms.
  • Toast: slide from bottom 12px over 220ms, auto-dismiss 4s, exit reverse.

9. Mobile strategy

  • Disable parallax, pinned sections, magnetic hover, and hover-only reveals below 768px.
  • Replace hover reveals with tap toggles and larger tap targets (min 44px).
  • Reduce stagger counts by 40% to avoid long sequences on small screens.
  • Prefer IntersectionObserver and CSS transitions over JS scroll tracking.

10. Reduced motion

  • All transforms beyond opacity removed; fades only, max 200ms.
  • Pinned sections become static stacks; horizontal progress becomes instant.
  • Infinite/looping motion disabled.
  • Respect prefers-reduced-motion: reduce via media query and JS check before arming observers.

11. Performance requirements

  • Animate only transform and opacity; never top/left/width/height.
  • will-change only on actively animating elements, removed after completion.
  • Grain/noise fixed, pointer-events none, never on scroll containers.
  • LCP under 2.5s, INP under 200ms, CLS under 0.1.
  • No window.scroll listeners; use IntersectionObserver or Motion useScroll equivalent.
  • Lazy-hydrate animation bundles below the fold.

12. Implementation architecture

  • Layer A (CSS): tokens, hover, focus, surface transitions. Works without JS.
  • Layer B (JS observer): reveals, progress lines, spotlight masking via requestAnimationFrame lerp.
  • Layer C (pinned scene): isolated client components with IntersectionObserver + CSS transitions; GSAP optional only for desktop pinned stacks.
  • Client boundaries via "use client" leaf components; server components render static layouts.
  • Cleanup on unmount: disconnect observers, cancel frames, remove listeners.

13. Accessibility

  • All motion pauses under reduced motion and on low-battery mode when available.
  • Focus-visible on every interactive element in signal color.
  • No content hidden solely behind animation; initial state opacity >= 0.01 for critical text.
  • Animation does not auto-play audio or video; media remains paused until interaction.
