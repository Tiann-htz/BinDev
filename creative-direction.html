BinDev, recut as a precision instrument.

Reading this as: B2B SaaS / studio landing for technical buyers and small-business founders, with a cold-luxury, instrument-grade language, leaning toward a graphite palette, Bricolage Grotesque display, restrained but motivated motion.

Dials: DESIGN_VARIANCE 8 · MOTION_INTENSITY 6 · VISUAL_DENSITY 4. Single accent. One theme (dark). No theme flip mid-scroll.

Narrative spine

Tool / precision instrument. The whole site reads like a machined object: calibrated spacing, hairline rails, tabular figures, a single accent that behaves like an LED status indicator. Nothing decorative. Every element earns its pixel.

Art direction

Ethereal Glass meets Soft Structuralism, but cooled down: deep graphite grounds, off-bone text, one acid-lime signal color used like a status light. Photography is cold, high-contrast, and architectural (concrete, brushed metal, screens in dark rooms). No warm stock. Backgrounds use a faint technical grid plus a single radial volumetric glow in the ledger corner. Grain is fixed, pointer-events none, barely visible.

Absolute-zero bans applied: no Inter/Arial, no Bootstrap 3-column grid, no sticky edge-to-edge navbar, no AI purple gradient, no generic box shadows, no meta-labels ("SECTION 01"), no em-dashes, no decorative dots, no locale/weather strips, no fake product UI built from divs.

Color palette (one palette, one accent, locked)

Graphite ground with an acid-lime signal. Desaturated everywhere but the accent, which is used only for the primary CTA, active states, and one "live" indicator per viewport.

#0B0F14 ink-950 ground
#111722 ink-900 surface
#1F2530 hairline / rail
#EAEFF7 bone primary text
#9BA6B5 muted secondary text
#B8FF3D signal (accent, CTA only)
#3DFFB8 signal-off (hover wash)

Semantic map: ground --bg, raised --surface, hairline --hair, primary --fg, muted --fg-muted, accent --signal. Accent saturation stays at 100% only inside the 12px mark, buttons, and one per-section indicator. Everywhere else it is tinted to 12% opacity.

Typography

  • Display: Bricolage Grotesque, 500-800. Hero at clamp(2.6rem, 5.5vw, 4.6rem), tight tracking -0.03em, max 2 lines.
  • Body: Plus Jakarta Sans, 400-600, 16px, leading 1.6, max 65ch.
  • Mono: JetBrains Mono for eyebrows, prices, figures, stack tags, table of contents.
  • Rules: no all-caps everywhere (only mono eyebrows, max 1 per 3 sections), tabular nums for all figures, italic reserved for emphasis inside the same family only, never mixed-family emphasis.

Layout system

  • Container: max-w-[1280px] mx-auto px-6 md:px-10, sections breathe at py-24 md:py-36.
  • Hero: right-text / left-image inverted composition, top padding capped at pt-24, max 4 text elements.
  • Feature grid: asymmetric bento, grid-flow-dense, cells sized to content count (N items to N cells, zero empty cells), at least 2 cells carry real imagery or tinted fills.
  • Case studies: sticky-stack on scroll (GSAP start: "top top", previous card scales to 0.92 and fades to 0.55).
  • Pricing: two columns, recommended tier emphasized by signal rail not height.
  • Footer: single row of three groups, no 4-column link farm.

Imagery, lighting, texture

  • Style: cold editorial photography, high contrast, desaturated 15%, duotone graded to ink + signal on case-study thumbnails.
  • Lighting: single top-left source across all visuals; shadows tinted to ink (not black). Spotlight borders on cards (cursor-driven, 1px, 120px radius).
  • Depth: double-bezel cards (outer shell bg-white/5 p-1.5 rounded-[2rem], inner core bg-surface rounded-[calc(2rem-0.375rem)], inset 1px highlight).
  • Texture: fixed grain overlay at 3% opacity, pointer-events none, never on scroll containers.
  • Background: ink ground + faint 24px technical dotted grid at 6% opacity + one radial volumetric glow (signal at 8% opacity) anchored top-right.

Motion choreography

  • Primary easing: cubic-bezier(0.32, 0.72, 0, 1), 600-800ms for entry, 200-300ms for interactions.
  • Hero: staggered mask reveal on load (label, headline, sub, CTA with 80ms offsets), background glow fades in.
  • Scroll reveals: translate-y-16 blur-md opacity-0 to rest over 800ms via IntersectionObserver; never window scroll listeners.
  • Button magnetic hover at MOTION 6: cursor proximity pulls 3px, spring stiffness 120, damping 18.
  • Respects prefers-reduced-motion: all transforms collapse to opacity-only fades.

Copy register

Plain, specific, no AI copywriting. Banned words: elevate, seamless, unleash, next-gen, game-changer, delve, tapestry. Numbers are real or explicitly labeled mock. One copy register per page (instrument-grade, declarative). No em-dashes: use hyphens or periods. No version labels, no locale strips, no scroll cues.
